# 陈晓铜的个人主页

基于 [Docusaurus 3](https://docusaurus.io/) 构建的个人主页与技术博客。

## 安装

```bash
yarn
```

## 本地开发

```bash
yarn start
```

## 构建

```bash
yarn build
```

构建产物会生成在 `build` 目录，可部署到 GitHub Pages 或其他静态托管服务。

## 部署

```bash
USE_SSH=true yarn deploy
```

或：

```bash
GIT_USER=Nicolerobinn yarn deploy
```
